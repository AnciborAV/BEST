# Правила работы над ОПОРОЙ

- Все тексты сайта выравнивать по ширине (text-align: justify). Последнюю строку абзаца не растягивать принудительно.
- В текстах сайта, документации и пояснениях пользователю использовать короткий знак «-» вместо длинных тире и типографских дефисов.
- Пользователь учится разработке: двигаться небольшими шагами, объяснять назначение каждого нового файла и показывать учебные листинги с подробными комментариями.
- Не добавлять новые функции без команды пользователя. Текущее содержание сайта должно оставаться минимальным.
